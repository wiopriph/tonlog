# Tonlog

Компактная англоязычная главная будущего сервиса учета спецтехники: описание продукта и форма раннего доступа. Nuxt 4, Nuxt UI 4, Tailwind CSS 4, TypeScript.

## Запуск локально

Нужен Node.js 24. Команды выполняются из папки проекта:

```sh
npm ci
npm run db:migrate:local
npm run dev
```

Используется локальный эмулятор Cloudflare D1. Данные хранятся в `.wrangler/state/v3` и не отправляются в настоящую базу Cloudflare.

## Проверка

```sh
npm run typecheck
npm run build
npm run preview
```

`preview` запускает production-сборку в локальном Workers runtime через Wrangler, обычно на порту 8787.

## Публикация

Полная инструкция: [DEPLOYMENT.md](./DEPLOYMENT.md). Нужно создать D1, заменить Database ID в `wrangler.jsonc`, применить миграцию и опубликовать Worker. Настоящие ресурсы Cloudflare из этой папки автоматически не создаются.

## Заявки раннего доступа

`POST /api/waitlist` проверяет email, приводит его к нижнему регистру и сохраняет в D1 через binding `DB`. Поля таблицы `waitlist`: `email` (уникальный), `created_at` (UTC), `source`. Повторные адреса игнорируются атомарно базой. При отсутствии базы или ошибке записи API возвращает 503, а форма предлагает повторить попытку.

Email не выводятся в логи и не доступны через публичный API. Список можно посмотреть в панели Cloudflare D1. Отправка писем пока не подключена. Старое файловое хранилище `.data/waitlist` больше не используется; нужные старые записи следует перенести отдельно.

Для проверки дерева зависимостей используйте `npm audit`. Ранее аудит отмечал предупреждения в транзитивных зависимостях Nuxt/Nitro; актуальный результат зависит от lock-файла и базы advisory. Принудительное понижение Nuxt для обхода предупреждений не выполнялось.
